# Packed sample material directory

Only place a binary here after recording its exact source, terms, authorization,
software/protector version and SHA-256 in `../manifest.json`. Binary files in this
directory are local assessment material and are excluded from Git by `.gitignore`.

Current non-commercial course samples are purpose-built crackmes obtained from
crackmes.one and credited to their authors:

- `aj21h-spaghetti-crackme.exe` — aj21h;
- `kowfsun-custom-packed-out.exe` — Kowfsun.

The site FAQ permits non-commercial course use with author attribution. Do not
republish these files as a public mirror; retain the manifest URLs and hashes.

Intake and benchmark analysis never execute the targets. Explicitly authorized
file-only UPX transformation is isolated from the original input.
