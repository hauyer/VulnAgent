## 二、检测对象

仅限本地部署、开源授权且经授权方确认的大模型服务软件及其源码，例如本地 Ollama 服务端、推理引擎组件和课程自建样本。目标名称、版本、路径、哈希：__________。

## 三、允许操作

- 本地静态源码审计：只读解析 AST、CFG、调用关系与数据流。
- 本地受控鲁棒性测试：仅使用空值、边界值、受限长度字符串和无害异常格式。
- 监控崩溃、异常退出、内存错误、超时和服务不可用。
- 记录源码位置、规则命中、污点/控制流路径、脱敏日志和修复建议。
- 测试结束后恢复干净快照或重建临时容器。

## 四、禁止操作

- 远程主机、互联网地址、第三方服务扫描或测试。
- 漏洞利用、代码执行类验证、权限提升、持久化或规避安全控制。
- 读取非实验所需的敏感文件、凭据、模型私有数据或用户数据。
- 将样本、日志、响应或任何实验数据外传。
- 生成或传播 PoC、利用代码、攻击载荷、绕过步骤。

## 五、证据留存与用途

证据仅保存在本地课程目录，按 Task ID、Finding ID 与 Evidence ID 关联；不保存原始动态测试输入和响应正文。报告仅用于课程设计、安全审计与防御研究，统一标注“仅用于安全审计与防御研究，仅限教学实验使用”。课程结题后按学校/授权方要求归档或删除。
