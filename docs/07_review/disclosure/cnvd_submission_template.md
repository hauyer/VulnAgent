# CNVD / CNNVD 漏洞提交材料模板（课程用）

> 用途：VulnAgent 披露管线（`docs/07_review/practice_requirements_review.md`
> P1-2）配套的提交材料模板。本模板用于**课程练习与流程演示**；真实提交
> 前必须满足 `submission_checklist.md` 的全部前置条件，并由有权主体提交。

## 一、基本信息

| 字段 | 内容 |
|---|---|
| 漏洞名称 | （如：某软件某功能存在XX类型漏洞） |
| 提交人/单位 | （课程练习：不可虚构，填"课程练习"并说明） |
| 提交日期 | YYYY-MM-DD |
| 目标软件 | 名称 + 版本号 |
| 漏洞类型 | CWE 编号 + 名称（如 CWE-89 SQL注入） |
| 危害等级 | 高 / 中 / 低（按 CNVD 等级定义自评） |

## 二、漏洞描述

```
[一段话描述：漏洞所在功能、触发入口、缺陷机理（如"未校验长度导致
缓冲区越界"），不含可运行攻击载荷]
```

## 三、影响版本与修复建议

| 项 | 内容 |
|---|---|
| 影响版本 | 列出受影响的版本范围（从厂商公告/补丁记录核对） |
| 不受影响版本 | 修复版本号 |
| 修复建议 | 描述建议修复方式（如"升级到 X.Y.Z"或"对输入增加长度校验"） |

## 四、复现步骤（验证材料）

1. 环境：操作系统、依赖版本、复现工具
2. 步骤：
   ```
   1) ...
   2) ...
   3) 观察结果（崩溃/Sanitizer 摘要/异常行为）
   ```
3. 证据材料清单（勾选，随附）：
   - [ ] 触发输入（脱敏后）或复现脚本
   - [ ] Sanitizer / 崩溃日志摘要（不附完整内存转储）
   - [ ] 修复版对照（同一输入在修复版干净退出）
   - [ ] 调用链 / 证据链引用（VulnAgent 证据 ID）

## 五、披露状态（课程诚实声明）

```
本材料为课程练习产出，未提交至任何国家漏洞库或厂商。
状态机终态：UNSUBMITTED。
```
